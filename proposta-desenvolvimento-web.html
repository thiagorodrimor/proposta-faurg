O que o Key Visual não é

O Key Visual é o sistema visual do site — não é criação de marca, logotipo ou manual de identidade visual, que são serviços separados. Se a sua empresa já tem identidade visual definida, o Key Visual é justamente a tradução dela para o ambiente web.
